What the project actually proves

✓The quality gate is real. A deliberately removed authorisation check passed all 179 unit tests; Selenium caught it, the build went red, and Promote was never entered.
✓Idempotency is measured, not claimed. A second ansible-playbook site.yml reports changed=0 — and the check names the offending task if it ever does not.
✓Rollback works under a minute. Image tag 17 → 15 pulled from the private registry, container replaced, data intact on the volume, verified from the Docker API rather than from the app’s own claim.
✓The image is hardened. The build stage is discarded, every stock Tomcat webapp removed, and the JVM runs as uid 999 as PID 1 after the entrypoint drops privileges.
✓Health is behavioural. Nine assertions — create a request, match it, fulfil it — not just an HTTP 200 from /actuator/health.
✓One command reproduces everything. scripts/demo-all.sh runs nine asserting steps commit-to-container in 151 s.
